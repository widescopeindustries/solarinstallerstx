## 📏 Post Best Practices

✅ **DO**:
- Keep text under 1500 characters (shorter is better)
- Include emojis for visual interest (2-4 per post)
- Use line breaks for readability
- Add clear call-to-action
- Include specific numbers/data when possible
- Link to relevant website pages
- Use high-quality images (min 400x300px)

❌ **DON'T**:
- Use ALL CAPS (except for emphasis)
- Keyword stuff
- Post promotional content only
- Use low-quality or stock photos
- Forget to add CTA button
- Post inconsistently
